# CampusFix

CampusFix — университеттегі мәселелер туралы өтініш қалдыратын оқу сайты. Мысалы, проектор істемесе немесе жарық жанбаса, оны сайтқа жазуға болады.

Бұл — оқу жобасы. Өтініштер университет қызметкерлеріне жіберілмейді.

## Сайтты қалай іске қосу керек?

1. Компьютерде Python 3.9 немесе одан жаңа нұсқасы болуы керек.
2. `start.bat` файлын ашыңыз. Немесе осы бумада терминалды ашып, `python app.py` деп жазыңыз.
3. Браузерде http://127.0.0.1:8001 адресін ашыңыз.
4. Сайт жұмыс істеп тұруы үшін терминалды жаппаңыз. Тоқтату үшін терминалда `Ctrl+C` басыңыз.

Қосымша Python кітапханаларын орнату қажет емес. Сайт осы компьютерде жұмыс істейді.

## Сайтта не істеуге болады?

- Мәселені және оның орнын жазу.
- Модель арқылы мәселенің санатын анықтау.
- Өтінішті қосып, тізімнен көру.
- Өтініштерді іздеу, санат және мәртебе бойынша сүзу.
- Мәртебені «Жаңа», «Қаралуда» немесе «Шешілді» деп өзгерту.
- Интерфейс тілін қазақша, орысша немесе ағылшынша ауыстыру.
- Оқыту және тексеру деректерін Excel форматында жүктеу.

«Кіру» және «Тіркелу» функциялары әлі жасалмаған. Олардың батырмалары әзірлену үстінде деген хабарлама көрсетеді.

## Машиналық оқыту

Сайтта **Multinomial Naive Bayes** әдісі қолданылады. Бұл — мәтінді жіктеу, яғни classification. Модель өтініштегі сөздерге қарап, мәселені бес санаттың біріне жатқызуға тырысады: техника, жиһаз, су жүйесі, интернет немесе электр.

Мысалы: «Проектор қосылмай тұр» → «Техника».

Бұл әдіс қарапайым және қосымша Python кітапханасын қажет етпейді. Баламалардың бірі — TF-IDF және Logistic Regression; олардың сапасы бұл жобада салыстырылған жоқ.

Модель негізінен қазақша мәтіндермен оқытылған, сондықтан мәселені қазақша әрі анық жазған дұрыс. Модель қателесуі немесе санатты анықтай алмауы мүмкін.

## Деректер мен нәтиже

- Оқытуға **160 мәтін** қолданылды.
- Тексеруге бөлек **25 мәтін** қолданылды.
- Модель 25 мәтіннің 23-ін дұрыс жіктеді: **accuracy — 92%**.
- Барлық мәтіндер оқу жобасы үшін Codex көмегімен жасанды түрде құрастырылған. Олар нақты адамдардың өтініштері емес.

Тексеру мысалдары:

1. «Видеоны тақтаға шығаратын проектор тоқтап қалды» → Техника — дұрыс.
2. «Шкафтағы сөре салмақ көтермей қисайып тұр» → Жиһаз — дұрыс.
3. «Телефоным университет желісін таппай тұр» → Жиһаз — қате, дұрыс санат — Интернет.

Тест шағын және оның нәтижелері жобаны дайындау кезінде қаралған. Сондықтан 92% нақты өмірдегі дәлдікке кепілдік бермейді.

Қателер матрицасы мен барлық тест нәтижесін көру үшін осы бумада мына команданы орындаңыз:

```text
python -X utf8 model.py
```

Accuracy, қателер матрицасы және тексеру мысалдарын презентацияда көрсетуге болады.

## Жоба файлдары

- `app.py` — сайт сервері және өтініштерді сақтау.
- `model.py` — модель және оны тексеру.
- `static/` — сайт беттері, дизайны және функциялары.
- `data/` — оқыту және тексеру деректері.
- `docs/` — қорғауға дайындық пен жеке үлеске арналған файлдар.

Әр қатысушы `docs/Үлес-және-ЖИ.md` файлына өз үлесін және ЖИ қолданғанын нақты жазуы керек.
