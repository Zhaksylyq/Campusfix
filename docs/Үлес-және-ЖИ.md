# Жеке үлес және ЖИ қолдану декларациясы

## Команда және қорғау бөлімдері

Төмендегі бөлініс презентацияға және қорғауға арналған ұсыныс. Әр қатысушы өз бөлімін түсіндіріп, жеке өзі орындаған жұмысын тиісті файлмен немесе тексеру нәтижесімен растауы керек. Тапсырар алдында кестені нақты орындалған жұмысқа сәйкестендіріңдер.

| Қатысушы | Қорғауда түсіндіретін бөлімі | Көрсетілетін материал |
|---|---|---|
| Жақсылық Бүркіт | Жобаның мәселесі, мақсаты, пайдаланушысы және сайттың артықшылықтары. | README.md; презентацияның 2–4-слайдтары. |
| Ақылбек Нұрдаулет | Жасанды деректер, модельдің жұмысы және балама әдіс. | data/README.md; model.py; презентацияның 5–7-слайдтары. |
| Айтмұханбетов Иасин | Сайт интерфейсі, өтініш жіберу және басқа тәсілдермен салыстыру. | static/; app.py; презентацияның 8–10-слайдтары; сайттың демо нұсқасы. |
| Дәулет Жігерхан | Модельді тексеру, accuracy, қателер матрицасы және шектеулер. | model.py; data/challenge.csv; test_app.py; презентацияның 11–13-слайдтары. |

Бұл кесте кімнің қай файлды жасағанын немесе тестті өзі орындағанын растамайды. Жеке үлес үшін нақты қандай өзгеріс, тексеру немесе талдау жасалғанын және дәлелін әр қатысушы өзі қосуы қажет.

## ЖИ қолдану декларациясы

**Қолданылған құрал:** OpenAI Codex. Нақты модель немесе нұсқа: қолданылған нұсқасы белгілі болса, тапсырар алдында толтырыңдар.

**Қолдану мақсаты:** CampusFix оқу жобасының идеясын талқылауға, сайт пен модельді дайындауға, жасанды мәтіндер құрастыруға, тексеруге және құжаттарды дайындауға көмектесу.

**Негізгі сұраныстар:**

- Кампустағы мәселелерді тіркейтін сайттың идеясын және құрылымын ұсыну.
- Мәтін бойынша мәселені санатқа бөлетін модель құру және деректерді көбейту.
- Сайттың интерфейсін, іздеуін, сүзгілерін және мәртебе көрсетуін жасау немесе түзету.
- Модель нәтижесін тексеріп, README, есеп және презентация дайындау.

**Codex көмегімен алынған немесе өзгертілген материалдар:** сайттың HTML, CSS және JavaScript файлдары; Python сервері мен мәтінді жіктеу коды; жасанды оқыту және тексеру мәтіндері; тесттер; README, есеп және презентацияның нұсқалары.

**Тексеру нәтижелері:**

- Модель бөлек 25 жасанды тест мәтінінің 23-ін дұрыс жіктеді: accuracy — 92%. Нәтиже `python -X utf8 model.py` командасымен қайта есептеледі.
- Тест мысалдарының бірінде «Телефоным университет желісін таппай тұр» мәтіні Интернеттің орнына Жиһаз деп қате жіктелді. Бұл модель нәтижесін сыни тексеру қажет екенін көрсетеді.
- Өтініш қосу және мәртебесін өзгерту автоматты тесттерде уақытша дерекқор арқылы тексерілді. Сайттағы іздеу мен санат сүзгісі браузерде тексерілді.
- Деректер жасанды, тест шағын және әзірлеу кезінде қаралған. Сондықтан 92% нақты өмірдегі дәлдікке кепіл емес және тәуелсіз соңғы бағалау ретінде көрсетілмейді.
