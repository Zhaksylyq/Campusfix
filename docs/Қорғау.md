# Қорғау жоспары

1. Мәселе: студент университеттегі ақау туралы кімге хабарлауды біле бермеуі мүмкін. Бұл жорамал, уақыт үнемі өлшенген жоқ.
2. CampusFix: ақауды сипаттау → модель санатты болжауы → өтінішті жергілікті сақтау.
3. Тақырып: 6-апта — мұғаліммен оқыту, мәтінді жіктеу; 7-апта — NLP.
4. Деректер: Codex көмегімен жасалған 160 оқыту және бөлек 25 тест мәтіні. Нақты адамдардың деректері емес.
5. Нәтиже: 23/25 (92%), қателер матрицасы және кемінде үш тексеру мысалы. Нәтиже жасанды деректерге қатысты; тәуелсіз бағалау емес.
6. Қате: «телефоным университет желісін таппай тұр» интернеттің орнына жиһаз санатына жіктелді. Модель сөз бен контексті қате түсінуі мүмкін.
7. Әр адамның нақты үлесі және ЖИ қолдану декларациясы. Команда мүшелері өздерінің шынайы жұмыстарын және дәлелдерін толтыруы керек.

Демо: «204-аудиторияда проектор қосылмай тұр» мәтінін енгізіп, «Санатын анықтау» батырмасын басыңыз. Өтінішті қосыңыз, күйін өзгертіңіз. Презентацияда accuracy мен қателер матрицасын көрсетіңіз. Қорғауда генеративті ЖИ қолданылмайды.
